## Installation

Install from PyPI using `uv`:

```bash
uv add bulk-note
```

Or, if you are working within an existing project with a `pyproject.toml`:

```bash
uv sync
```

## Development Setup

Clone the repository and install dependencies (including dev dependencies) with:

```bash
uv sync --group dev
```

## Running Tests

```bash
uv run pytest
```
